# Methods behind the estimates

[methods.md](methods.md) connects the physical circuit, flag model, rare-event estimator and phase fits to the reported qubit counts. It retains the unresolved [ancilla-path and idle-noise choices](methods.md#circuit-ambiguities), the distinction between an event and an X error, the decoder comparison, false-alarm bounds, transfer assumptions and error-counting convention.

Use the [results guide](../results/README.md) to find the corresponding samples and [REPRODUCE.md](../REPRODUCE.md) to rebuild the calculation.
