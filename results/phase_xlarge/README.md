# Longer-block memory phase samples

Physical X-memory samples with longer repetition blocks. They extend the distance dependence used to assess the complete-memory phase model.

[Summary table](../summary/phase_model.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/phase_xlarge.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
