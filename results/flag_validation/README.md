# Direct checks of rare-event estimation

Direct block-level Monte Carlo and matching stratified estimates at noise levels with observable failures. These samples test the Poisson model and low-noise reweighting used for the headline.

[Summary table](../summary/validation.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/flag_validation.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
