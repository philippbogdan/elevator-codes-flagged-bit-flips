# Low-noise memory phase samples

Physical X-memory samples extending into lower noise, with reference points in the fitting range. The lower-noise subset checks predictions excluded from the phase model's fit.

[Summary table](../summary/phase_model.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/phase_xlow.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
