# Ancilla-noise sensitivity

Physical X-memory samples with varied ancilla-noise scaling. They help separate data-block and moving-ancilla contributions to the phase rate.

[Summary table](../summary/phase_model.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/phase_ancdiag.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
