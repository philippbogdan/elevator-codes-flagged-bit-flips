# Main flag settings

Stratified bit-flip samples for the paper outer codes across flag efficiency, location coverage and timing. These are the main evidence behind the modelled qubit saving.

[Summary table](../summary/headline.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/flag_main.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
