# Ancilla-path comparison

Direct block-level samples comparing full-column sweeps with shorter ancilla paths. They show why the unspecified path matters to agreement with the paper.

[Summary table](../summary/schedule_comparison.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/sched_local.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
