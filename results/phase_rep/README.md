# Isolated repetition-code samples

Phase-error samples for the inner repetition code, decoded with PyMatching. Their large-distance decay supplies the phase model and its held-out checks.

[Summary table](../summary/phase_model.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/phase_rep.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
