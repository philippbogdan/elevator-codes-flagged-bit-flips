# Certain-X flag sensitivity

Samples in which a flag certifies an X error. This is more information than an erasure-event flag supplies and is a sensitivity case, not the headline model.

[Summary table](../summary/assumptions.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/flag_herald.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
