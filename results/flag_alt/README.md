# Alternative outer codes

Stratified samples for Hamming and extended Hamming outer codes. They support the larger conditional saving; the phase-rate formulas are transferred to these codes rather than fitted to each one.

[Summary table](../summary/headline.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/flag_alt.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
