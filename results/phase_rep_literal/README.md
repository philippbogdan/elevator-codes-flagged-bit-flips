# Extra-idle phase samples

Isolated repetition-code samples with additional idle ticks representing logical-operation layers. They support the approximate phase-noise sensitivity under the literal reading.

[Summary table](../summary/literal_reading.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/phase_rep_literal.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
