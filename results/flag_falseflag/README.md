# False-alarm sensitivity

Stratified samples with false flags, including cases using analytic bounds. They quantify how erroneous location information can remove a saving that survives with no false alarms.

[Summary table](../summary/assumptions.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/flag_falseflag.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
