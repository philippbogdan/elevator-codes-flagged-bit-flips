# Idle-noise sensitivity

Flagged bit-flip samples with idle noise on every waiting block, including logical-operation layers. They test the effect of the literal noise reading against the headline circuit choice.

[Summary table](../summary/literal_reading.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/flag_literal.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
