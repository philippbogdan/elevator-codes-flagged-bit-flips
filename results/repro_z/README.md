# Unflagged bit-flip comparison

Physical Z-memory samples for the main outer codes under alternative schedules and idle-noise readings. They compare the implemented circuits with the published bit-flip fits.

[Summary table](../summary/reproduction.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/repro_z.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
