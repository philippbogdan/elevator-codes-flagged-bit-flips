# Higher-noise bit-flip samples

Stratified samples at the bit-flip rate used by the higher phase-noise comparison, including larger distances and timing sensitivities. They test the distance transfers behind predicted rate floors.

[Summary table](../summary/pz1e2_floors.md) gives the derived comparison. Each JSON stores its `spec`; [the matching task file](../../tasks/flag_pz1e2.jsonl) reruns this folder. [Methods](../../docs/methods.md) explains the estimator and assumptions, and [reproduction](../../REPRODUCE.md) covers fresh samples and saved-output checks.
